- **Fixed**: a negative `set ttl` over the WebSocket protocol is refused with an `exception` reply instead of reaching an assert that aborted a debug server (and stored a negative ttl in a release one). `--retention_seconds` above 4000000000 (about 127 years) is now refused at startup with a clear error, and the retention window is capped in both places that converted it to nanoseconds (the time-resolution sampler and the retention sweep), where a value above about 9.2e9 overflowed (#1007).
