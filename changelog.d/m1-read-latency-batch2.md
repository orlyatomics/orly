- **Changed (performance)**: reads that return records, sets or variants (such as `point` and `page`), and reads that skip keys before taking a slice, are about 20–26% faster. `Var::StateToJson` now converts records, `$which` variants (decoding only the active arm), sets, durations and time points straight from the Sabot state instead of falling back to `Var::ToVar` and `Type::ToType`; `TSession::TryCore` and `TryBatch` share the execution `TSuprena` with `TMethodResult` instead of deep-copying the result core into a second arena; and `TKeyGenerator::TCursor::operator bool()` checks whether the underlying key cursor is valid without decoding the key tuple when a row is only being skipped. On a settled M1 store, 1-session `point` p50 drops from 217 µs to 160 µs (p99 845 µs to 534 µs) and `page` p50 drops from 3.99 ms to 3.10 ms (p99 6.29 ms to 4.89 ms).
