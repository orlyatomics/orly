- **Changed (breaking)**: replication uses the words primary and replica ([#1034](https://github.com/orlyatomics/orly/issues/1034)). The old flag names are gone, with no aliases: `--slave_port_number` (and `-spn`) is now `--replica_port_number`, `--slave_bind_address` is now `--replica_bind_address`, `--address_of_master` is now `--address_of_primary`, and `--starting_state=SLAVE` is now `--starting_state=REPLICA`. A script or unit file that still passes an old name fails at startup with an unknown-flag error. Replication log lines say primary and replica. The wire protocol and on-disk formats are unchanged. Docs, tests and scripts use the new names, and CI treats a push to `main` like a push to `master` (cache saves included) so the default branch can be renamed without a gap.
