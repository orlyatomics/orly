- **Changed**: replication uses the words primary and replica ([#1034](https://github.com/orlyatomics/orly/issues/1034)). The flags are now `--replica_port_number`, `--replica_bind_address` and `--address_of_primary`, and `--starting_state` takes `REPLICA`. The old names (`--slave_port_number`, `-spn`, `--slave_bind_address`, `--address_of_master`, `--starting_state=SLAVE`) keep working for this release; `orlyi` prints a one-line deprecation warning on stderr when one is given. Replication log lines say primary and replica. The wire protocol and on-disk formats are unchanged. Docs, tests and scripts use the new names, and CI treats a push to `main` like a push to `master` (cache saves included) so the default branch can be renamed without a gap.
