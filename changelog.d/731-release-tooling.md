- **Changed**: `tools/npm_publish.sh` is now idempotent. It skips any package whose version is already on the npm registry, and after publishing (or finding) the driver it waits, bounded and with progress output, until `@orlyatomics/orly@<version>` resolves before building `orly-mcp` and `orly-repl`, which previously failed with ETARGET against a driver the registry had not yet made visible. `--dry-run` still works, and the header notes that each publish needs an npm 2FA code and so must run from an interactive terminal. `clients/go/README.md` now points at the `clients/go/v0.2.0` tag, and `CONTRIBUTING.md` gains a "Releasing" section that includes the Go module tag step (#731).
