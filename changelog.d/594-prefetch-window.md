- **Fixed**: a sequential reader's prefetch now fetches its whole window. `TStream` prefetches the pages ahead of a reader as runs of consecutive pages, but it started counting each run at 0. So the last page of every run, and any page on its own, was left out (a 4-page window fetched 3), and the reader stopped to read that page synchronously when it got there. Every page is still read from disk once, so the total I/O is unchanged. More of it is now prefetched: reading one 16-page block sequentially, synchronous page reads drop from 8 to 5 (#594).
