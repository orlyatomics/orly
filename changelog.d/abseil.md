- **Changed**: Abseil (`libabsl-dev`, 20220623 LTS; the runtime image adds `libabsl20220623t64`) is now a build and runtime dependency, linked into every jhm configuration. Its first user is the type interner (`TTypeByKey` in `orly/type/managed_type.h`), now an `absl::flat_hash_map`. On a hit-path microbenchmark (`orly/type/managed_type.test`, release, arm64 container) a `Get` over 1,000 interned keys costs the same as before (22.1 vs 21.7 ns, 7 runs of 2M lookups each) and over 100,000 keys about 15–20% less (66–73 vs 80–89 ns); lookups are mostly the shared lock and `weak_ptr::lock`, so do not expect more than that. Building from source now needs `libabsl-dev` installed.
