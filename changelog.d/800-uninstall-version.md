- **Fixed**: `uninstall` removed a package by name and ignored the version, so `uninstall xa.1` removed an installed `xa.2`. It now refuses a version other than the installed one with a typed error (`TManager::TVersionNotInstalledError`) that names the installed version, and a batch uninstalls nothing unless every entry matches. Installing a new version of a package now also clears the persistent record of the version it replaced, so after the new version is uninstalled a restart doesn't bring the old one back; `tests/restart_test.sh` covers the refusal and that neither version returns (#800).
