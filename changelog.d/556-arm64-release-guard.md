- **Added**: an `aarch64 release smoke` CI job (`tools/maint/arm_release_smoke.sh`) builds `orlyi` and `orlyc` release on an arm64 runner. It compiles a package under a deadline (the #554 hang) and writes through every POV flavour on 20 fresh servers (the #578 segfault). On a crash it names the faulting function from the kernel log. The existing aarch64 job builds debug, and neither bug reproduces at `-O0`. A new lint, `tools/maint/lint_fiber_tls.py`, fails on any bare `__thread`/`thread_local` that isn't allowlisted with a reason, which makes the hazard class deterministic on every arch. Run against master before #578's fix, it flags exactly the three variables that fix converted (#556).
