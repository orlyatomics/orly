- **Fixed (performance)**: A fiber runner now drains its handoff slots on every lap. It used to drain them only on laps that found its inbound queue empty, so a frame that called `YieldSlow()` sat in its own runner's handoff slot for many laps while other threads kept handing that runner frames. With the read pacer from #1016 and an ingest load running, point reads big enough to yield had a p50 of 7.0 ms. With this fix it is 1.6 ms. Within a lap, inbound frames still run before handed-off ones.
