- **Changed (performance)**: a memory-layer pattern seek now orders the pattern against each key core to core, copying the pattern's tuple elements once per seek and falling back to the Sabot comparison only for floating-point members or shapes it can't place, instead of building a Sabot state pair (with a `dynamic_cast` per member) for every key it compares. A ranged walk over a disk file now finds the end of its range by galloping only as far as the walk has actually gone, instead of locating the end up front, so a walk that stops early probes less. Results are unchanged; new tests check the fast order against Sabot and reuse of a pooled range walker across files, including after a file is released (#1041).
