- **Fixed**: `Base::TUuid` had an implicit `operator bool` and no `operator<=>`, so in C++20 a `std::pair` or `std::tuple` of UUIDs compared each UUID as a bool and every pair of non-null UUIDs looked equal. A `set<pair<TUuid, TUuid>>` therefore matched any lookup and dropped any second insert. That is why a write the slave had acknowledged could be invisible on the master's global POV for ~80 ms (#894): the test's `WaitForReplication` returned before Tetris promoted the write. It also affected the leaked-block check in `open_check.cc`, which keys a set by `(file uid, gen)`. `TUuid` now has `operator<=>` and an explicit `operator bool`. The `WaitForGlobalVal` workaround from #882 is removed, and the test helper waits for the global POV's acknowledgement only where a test reads the global POV.
