- **Fixed**: SIGTERM no longer waits for a running disk or tail merge step to finish. `StopMergeRunners()` used to join each disk-merge loop only after its current `StepMergeDisk` or `StepTail` returned, which with a backlog of hundreds of layers took minutes (323 s in one run, past the 120 s a harness allows before SIGKILL). Both `TMergeDataFile` (including arena, key, hash, and update-index passes) and `TFoldDataFile` now check the shutdown flag as they work, free their partial output, and hand the input layers back untouched so the merge is queued again on the next start (#927).
