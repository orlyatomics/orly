- **Changed (build)**: `make release-pgo` now also trains on a real volume (`tools/pgo/train_disk.sh`): a sparse file on a loop device, write-heavy ingest with disk merges, a clean stop and a reopen. The smoke-only profile left the disk merge, WAL and disk-controller code untrained, and on the read-latency scorecard in `docs/tuning.md` a build with that profile let write waits reach 5 to 12 s where the same source with a disk-trained profile stayed under 1 s. The disk training needs Linux and passwordless `sudo` (`losetup`, `setcap` on the instrumented `orlyi`); `--no-disk-train` leaves it out, and `docker build --build-arg PGO=1` passes that because a build container cannot attach a loop device.
