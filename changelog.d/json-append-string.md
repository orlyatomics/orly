- **Changed (performance)**: JSON string output finds the next character that needs escaping eight bytes at a time instead of one. The text written is unchanged byte for byte. With 64 concurrent sessions on a RAM-backed store, server CPU per read fell by about 3% on integer range queries (3.53 to 3.43 ms), about 2% on a mixed read load (1.60 to 1.57 ms) and about 4% on uuid-expand reads (.087 to .082 ms). Throughput is within noise; the gain is CPU per read. Single-session point reads are unchanged.
