- **Fixed**: `orlyc` failed with "Unable to open file ... for writing IR to" on a record or variant type whose mangled name outgrew a file name, which a moderately nested type (a record holding a variant whose arms hold records) does. The generated header under `orly/rt/objects` keeps the mangled name while it is at most 200 bytes, and is otherwise named `H` and a 128-bit hash of the mangled name in hex, in the emitter and in every `#include`. The C++ class names are unchanged, and the file name stays deterministic, so packages still share headers. Existing short-named headers are unaffected (#815).
