- **Changed**: the README no longer describes the published image as `linux/amd64` running under emulation on Apple Silicon, or aarch64 as "known to work, not yet released against". Both were true when written and stopped being true at v0.1.0: the image is a multi-arch manifest whose arm64 half is built on a native runner and gated by the same MCP, in-container `orlyc` and REPL smokes as the amd64 half. The platform section now also records the one aarch64-specific defect found so far (#554) and that it reproduced only in release builds, which is why the arm `make test` job stays informational and the coverage that matters for that class is a release-build `orlyc` run (#556).
