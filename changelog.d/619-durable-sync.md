- **Fixed**: a durable file (where session and POV saves go) entered the file map before its blocks were synced. The file map's own write syncs only the device that holds its log sector, and the file's blocks are striped across the others, so a power loss could leave an acknowledged save in the map with its blocks never written, and the next start aborted reading it. The durable writer and merger now sync the file's blocks before recording it, as data files already do. This costs one more sync per durable flush (#619).
