- **Fixed (memory)**: orlyi no longer holds memory it has finished with long after a read burst or a disk merge. Each runner now frees, every ten seconds, the pooled file walkers that no read needed since the last time, instead of keeping as many as were ever out at once until the file merged away; and after each disk merge, tcmalloc's free page heap beyond 256 MiB goes back to the kernel. On the M1 harness's post-ingest store, after a read ladder of up to 256 sessions and five idle minutes, RSS was 5.0 and 6.0 GiB in two runs against 13.8 and 14.1 GiB before (budget 6 GiB), with read throughput unchanged. Peak RSS during the ladder is still above the budget: merge working memory and the walkers a heavy read load keeps in use are not in the memory plan yet.
