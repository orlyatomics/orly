- **Added (example)**: `examples/grc20-pov/claims.orly`, a knowledge-graph package that stores claims rather than plain triples. Each statement keeps the source that asserted it, so two sources asserting the same value stay two claims, each with a confidence, a time qualifier and its own citations. Reads take the set of sources the reader trusts and return an honest answer: agreed, a conflict with every position and its sources side by side, an unknown value, no claim, or a claim only from unselected sources. Identity is the entity id, never a name. Methods cover point reads by id, one-hop neighbours in both directions, a keyset-paged range over a numeric property, and cross-source listings (`catalogue`, `disputes`). `run-claims.sh` runs it end to end in CI, the lang_test suite compiles it as `tests/lang_tests/samples/kg_claims.orly`, and the example README walks through it (#747).
