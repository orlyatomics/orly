- **Added**: an interactive browser playground for Orlyscript in `examples/playground/`. Features a code editor with real-time syntax highlighting, one-click remote package compilation and installation over WebSocket, an interactive method runner discovering exported package functions via `list packages;`, and a real-time console log. Preloaded with three canonical examples: an atomic Counter with commutative `+=` and POV branch isolation, the GRC-20 knowledge-graph event log with `reduce` replay and exhaustive `when` matching, and the parimutuel Prediction Market. Supported by a WebSocket session proxy with idle session timeouts, shared secret authentication (#710), read budgets (#694), and a `docker-compose.yml` for local execution via `docker compose up` (#740).
