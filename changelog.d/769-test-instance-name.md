- **Fixed**: the graceful-stop, kill-campaign (including `SIGNAL=TERM`) and restart tests no longer reuse fixed disk instance names across runs. Each run has its own instance, reused only for its own restarts, so overlapping runs on separate ports and retained images cannot make another run discover the wrong loopback volume. Loop devices are still detached on exit; the Python drivers still retain failure evidence and honor `--keep`. This addresses the test-isolation trap in #769, not the server's graceful-stop durability gap.
