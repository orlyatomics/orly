- **Fixed (undefined behavior, found by a UBSan build)**: `TAnyBgGenerator::KeepGoing` was never initialised before the generator started, so `Swap` of two unstarted generators read an indeterminate `bool`; it now starts `true` as its comment says (#996). `TCore::InitStr` and `InitBlob` no longer pass a null pointer to `memcpy` for an empty string or blob, and `TRegexMatcher::Match` passes `Buf.data()` rather than `&Buf[0]` to `regexec`, which indexed an empty vector for a pattern with no capture groups (#997). Two tests built bit masks with an `int` shift past its width (`base/murmur.test`, `orly/indy/disk/util/corruption_detector.test`); they now shift a 64-bit value (#998).
