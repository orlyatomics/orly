- **Changed (performance)**: a point or range read over many disk layers hashes its key once instead of once per layer. `TRepo::TPresentWalker` now hashes the key before building the per-layer walkers, so each layer's copy of the key carries the cached hash into `FindInHash`. In one readtrace profile of a join-heavy read workload under ingest, `TKey::GetHash` was about 9% of fast-runner CPU, nearly all of it this repeated hashing. The hash value is unchanged.
