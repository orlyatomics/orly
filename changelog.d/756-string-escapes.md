- **Fixed**: The Python, Go and TypeScript clients now escape newlines, tabs, carriage returns and every other control character in a string argument (as `\n`, `\r`, `\t` and `\xNN`), so text containing line breaks can be written through `call`; before, the statement was refused by the lexer. The lexer's `\xNN` string escape, which refused every value because it parsed the wrong buffer, now works. A client smoke round-trips such strings through all three clients (#756).
