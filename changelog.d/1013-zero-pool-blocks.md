- **Fixed**: buffer-pool blocks are now zeroed when they are handed out. The disk writers send whole 64 KiB pool blocks, so the unwritten tail of each data-file section used to carry whatever a reused block held before, and the bytes of a written file depended on earlier writes in the same process. Written files are now determined by their own contents alone; the fold byte-identity test pins the source file's bytes as well as the fold's, and a new test checks that a file written after a marker-filled one carries none of its markers. Zeroing a block costs about 3 µs (#1013).
