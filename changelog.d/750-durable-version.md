- **Added**: `durable_version {pov};` (WebSocket) replies `{pov, durable_version}`: the highest version of the POV, in the numbering a write receipt's `version` uses, that the server knows to be in a data file on disk, or `null`. For a POV promoting into the global one, Tetris records each promoted update's global version and the query maps the global durable version back. Repo tracks the highest synced sequence number of its data files. Wait-for-durable and batch receipts are not included (part of #750).
