- **Fixed**: the disk engine's cache callback had no `break` after `CacheAll` or `ClearAll`, so each fell through into the page-only case. Every cached write (each out-stream block and each merge output block) copied every page into the page cache twice, and every `ClearAll` cleared every page twice. Nothing was corrupted, but the page-cache work on the write path was doubled. The simulated engine had the same switch and gets the same fix ([#923](https://github.com/orlyatomics/orly/issues/923)).
