- **Fixed**: `orlyc` no longer fails a package with many tests partway through with `std::bad_alloc`. Its embedded test server kept every test section's and case's pov, and its repo, until the run ended, and a repo with writes also pinned itself because paused writes are never promoted, so the repo data-layer pool (512) ran out after about 300 cases. Each test pov is now made with a zero ttl and destroyed as soon as its section or case finishes. A generated 1,000-case package that stopped at case 285 now passes, and 4,000 cases run with the data-layer pool's use flat. CI compiles a generated 600-case package to keep it that way (#683).
