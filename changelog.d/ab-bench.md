- **Added**: an `ab-bench` workflow (manual dispatch) for comparing two commits' performance on the same runner. Each shot builds release `orlyi` and `orlyc` at both refs, then `tools/maint/ab_bench.py` runs one command against each build, alternating AB, BA, ... for several rounds. It reports each metric's median per arm and the median of the per-round B/A ratios. The command and its harness come from the dispatching ref, so both arms run the same workload. Commands report numbers as `METRIC <name> <value>` lines, and the pool-pressure smoke now prints writes per second and the peak Update pool for each phase. This replaces the throwaway probe branches used for #584 and #587. Comparing runs from different machines once made #587 look 14% slower when it wasn't.
