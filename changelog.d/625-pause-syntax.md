- **Fixed**: the TypeScript and Python clients' `pause` and `unpause` sent `pause pov "<id>";`, which the server's grammar rejects; it takes the POV id in braces: `pause {<id>};` (`pov_status_stmt` in `program.nycr`). Both clients now send that, and `docs/PROTOCOL.md`, which documented the wrong form, is corrected. The new-POV smoke now pauses and unpauses a shared child POV from both clients and requires `"paused"`/`"unpaused"` and a working write and read afterwards (#625).
