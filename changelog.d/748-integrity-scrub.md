- **Added**: online integrity scrub of a serving store (#748). Audits block accounting and sequence ranges against a consistent file map snapshot, verifies data and durable file decodability and page/block checksums, and validates index key ordering at `DiskPriority::Low`. Runs periodically via `--scrub_interval` (yielding every `--scrub_yield_every_n_keys`, default 256) or on demand via `POST /scrub` or `GET /scrub` on the reporting port. Results are published to the reporting status line (`Integrity Scrub = ...`) and syslog. Also updates `--check_only` to run the full scrub on a stopped store, exiting 0 on clean, 1 on non-fatal problems, and 2 on fatal/unsafe corruption.
