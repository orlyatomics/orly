- **Changed (performance)**: WebSocket replies are written straight into the reply text from the method result's state, with no JSON tree in between. Records (including `$which` variants), sets, optionals, maps, lists and addresses are all written directly; only sized ints, chars, floats, blobs and a few other rare kinds still take the old var path for that part. The reply envelope (`id`, `receipt`, `result`, `status`, `version`) is also written as text. The bytes on the wire are unchanged. Formatting a 150-byte record is 1.4x faster than before, a 100- or 1000-row page 1.2x, and a 100-key map 2.8x (release build, arm64).
