- **Fixed**: a memory merge that had written its file but found no pool room to publish it slept on the merge runner until room appeared. Every repo's memory merge runs on that runner, and another repo's merge is often what frees the room, so the wait could last until shutdown, with no repo's memory merging meanwhile. The merge now keeps its layers taken, re-queues itself with the same backoff, and finishes the publish at the start of its next turn, so the runner moves on to other repos (#691).
