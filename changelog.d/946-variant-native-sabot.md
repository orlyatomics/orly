- **Changed (performance)**: a variant value whose arms are all scalars, records, containers of them or other variants now converts to its storage record natively, without going through `Var` (#946). The compiler generates a `Native::VariantArms<>` for each such variant, and `Native::Variant<>` (`orly/native/variant.h`) builds the fixed-shape `$which` record type and state straight from the value. Returning or writing one of these values no longer interns the variant type, takes the interner lock or builds a `Var` per value. Recursive variants, mutually recursive groups and variants with an arm that holds an optional, an address or another type without a native sabot keep the `AsVar()` path. The bytes written and the types produced are unchanged.
