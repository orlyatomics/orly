- **Added**: an exhaustive small-scope model test of disk merge and version retention rules (`merge_retention.test.cc`) and pure retention policy functions (`orly/indy/merge_retention.h`). The model generates every sequence of repo events (writes, flushes, merging adjacent files, reader opens/releases, retention window advances) across keys up to a bounded depth. After each event, all allowed reads across all versions are checked against an oracle computed from the complete write log, verifying that reads outside the retention window are refused with `version_unavailable` and never answered from partial state. Deliberately broken variants (dropping non-superseded versions, dropping versions inside the window, dropping versions held by open readers, merging non-adjacent files, and partial-state answering) are tested as negative controls and each is detected and failed by the oracle (#856).
