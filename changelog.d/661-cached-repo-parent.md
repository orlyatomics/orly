- **Fixed**: a slave no longer segfaults on the first write to a POV created while the pair was up. The slave closes its copy of a new POV's repo straight away, so the repo goes into the repo cache, and caching nulled the repo's pointer to its parent while the repo still claimed one. Nothing restored it on reopen, so the replicated write's Tetris join dereferenced null. A cached repo now keeps its parent open until the cache discards it, so a repo's parent is live for as long as the repo exists. The same fix covers reads that fall through a reopened cached POV to its parent, and unpausing one (#661).
