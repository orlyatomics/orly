- **Fixed**: Storing or reading a variant with an optional arm (`<| E(str?) | F(int) |>`) aborted a debug `orlyc` on an optional-of-optional assertion. The stored record keeps one optional per arm, so `E(str?)` is stored as `str??`, which keeps an untaken arm apart from a taken arm with an unknown payload. Release builds already stored exactly that and read it back correctly, so no stored data changes; the debug build now accepts it ([#978](https://github.com/orlyatomics/orly/issues/978)).
