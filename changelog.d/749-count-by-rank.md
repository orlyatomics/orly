- **Added**: a key-only range count no longer reads every key of a disk file that it passes. Wherever only one file holds the keys up to the next key of any other layer or POV, the count takes their number from the file's sorted key index by rank, less the tombstones among them. The tombstone count of each block of 2048 keys is read the first time a count covers it and is then kept with the file for its life, so a repeated count reads only the blocks at the ends of each stretch. The disk format is unchanged. Counts give the same answers and charge the read budget the same rows as before; a key pattern with a descending, optional or nested member, and a file only partly inside a snapshot's window, still count by walking (#749).
