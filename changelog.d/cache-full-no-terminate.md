- **Fixed**: the server no longer terminates when its page cache has no free page while a merge is writing. A disk file's write also copies each page into the cache, and with every cache page held by readers (many layers under many concurrent reads) that copy threw. When it happened in the write-out a stream does as it is destroyed, the throw left a destructor and ended the process. Caching a written page is now best-effort: a page that can't be cached is read from disk later. And a stream whose last write-out fails frees its buffers and reports the failure to the file's owner, which fails that merge or flush instead.
