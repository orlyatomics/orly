- **Added**: `try {pov} pkg method <args> <{.receipt: true}>;` returns a top-level `receipt` (`{pov, version, durability}`) when the call committed a write. `version` is the repo sequence number of the committed update and rises with each commit to the POV; `durability` is `"memory"`, the level the server acknowledges at. A read has no receipt, and without the option the reply is unchanged. Batch calls, wait-for-durable and a durable-version query are not included (part of #750).
