- **Added**: store format version 1 as default and auto-upgrade of version 0 stores for durable acknowledgments (#755 Stage 3). Store creation defaults to format version 1 with preallocated WAL rings; opening version 0 stores with durable acknowledgments upgrades in place; stores with future format versions (> 1) are refused; downgrade is supported via `orly_dm --downgrade-format` when the log contains no uncheckpointed records; server flag `--durable_acks` defaults to `"local"` on disk; kill campaign verifies zero acknowledged safe writes lost across 40 kills under power-loss negative controls (`--wal_no_sync`, `--wal_early_ack`); and `docs/durability.md` documents the new contract.
- **Fixed**: the WAL head now advances as root data files become durable, so the ring no longer fills and stalls durable commits under sustained load (#755). Recovery restores safe POVs in dependency order from their newest `Pov` record, and a restart keeps the groups after the head so the next checkpoint can name them. A safe POV that never promotes still holds the head; once the ring is full, writes wait rather than lose data (`docs/durability.md`).
