- **Changed**: the disk cache and fiber scheduler now use `__builtin_prefetch` instead of `_mm_prefetch`/`<xmmintrin.h>`. Identical codegen on x86-64 — gcc lowers locality 3 and 2 to `prefetcht0`/`prefetcht1`, which is exactly what `_MM_HINT_T0`/`_MM_HINT_T1` emitted — but it also compiles on aarch64, where the SSE header does not exist. These were the only x86-specific constructs in the tree: there is no inline assembly anywhere, and the fiber fast path is `setjmp`/`longjmp` bootstrapped from `ucontext`, both POSIX, so there is no hand-rolled context switch to port. Verified with an explicit-instantiation probe, since every changed cache site lives inside `TCache<PageSize>` and `-fsyntax-only` on an includer does not compile class-template member bodies (#548).
- **Added**: an informational `aarch64 build` CI job (`ubuntu-24.04-arm`, `continue-on-error`) running `make debug` + `make test`. aarch64 has never been a supported platform, so this reports whether it could be — with evidence rather than opinion — without gating master. It matters because the published docker image is amd64-only, so Apple Silicon users hit a platform-mismatch warning on the first command in the README (#548).
- **Fixed**: dropped `-msse2` from `bootstrap.sh` (both seed compiles) and `root.jhm`. It was a 32-bit-x86-era leftover and a verified no-op on the only supported platform — `g++ -dM -E` emits a byte-identical macro set with and without it on x86-64, `__SSE2__` included — while being a hard `unrecognized command-line option` error on aarch64, which killed the bootstrap before a single translation unit compiled (#548).
