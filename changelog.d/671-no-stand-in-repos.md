- **Fixed**: a slave joining no longer makes the master build empty stand-in repos for povs that have gone, and a new pov can no longer be made under a pov whose state is gone. Every pov with a ttl leaves an entry in the system repo, and nothing ever removed one. A slave's join walked every entry ever written and opened each repo by force, which for a gone pov builds an empty repo with no parent; the master inventoried that to the slave, and with no repo cache it aborted, because the stand-in went while the join's sync view still held its layers. The join now inventories only live repos and pins each one until the sync is done, and an entry goes with the next repo creation once its repo is discarded, or, after a restart, once its repo is found gone. Separately, after a restart a pov made under a pre-restart shared pov got an empty stand-in as its parent and read nothing through it; it is now refused, as the pre-restart pov itself is (#671).
