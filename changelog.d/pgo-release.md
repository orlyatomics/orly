- **Added (build)**: `make release-pgo` (and `docker build --build-arg PGO=1`) builds `orlyi` and `orlyc` profile-guided: an instrumented build, a training run of the repository's own smokes (`tools/pgo/pgo_build.sh`), then a rebuild with `-fprofile-use`. `PGO_FLAGS=--march=x86-64-v3` additionally targets Haswell and later CPUs. The default `make release` and image builds are unchanged. How to regenerate the profile is in `docs/pgo.md`.
