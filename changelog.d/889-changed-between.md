- **Added**: `keys (T) @ <[pattern]> changed between (v1, v2)` (#889, #745): the keys of the pattern whose value differs between two versions of the global POV, or that exist at only one of them, in either order of the versions, with the `after`/`from` bound and `take`/`skip` as usual (`changed between` goes before the bound). A rewrite to the same value is not a change. It walks both versions together, so its cost follows the pattern, not the history. It reads the global POV only (a method run on a private POV, such as a test, gets a runtime error), and a version outside the kept history replies `version_unavailable`. A call on the global POV has to name a version to read at (`.at`). `changed` and `between` are now reserved words (still fine as record field names). Also fixes `try {global POV} ... <{.at: V}>` against a real server, which failed with "durable object doesn't exist".
