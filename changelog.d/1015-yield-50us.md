- **Changed (performance)**: `--read_yield_us` now defaults to 50 µs instead of 1000 µs ([#1015](https://github.com/orlyatomics/orly/issues/1015)). A point read lands on a fast runner that is often running several long reads in turn, and it waits for each of them to finish its slice, so the old default let it wait several milliseconds. With 64 sessions running a mix of point, range and paged reads, the p99 of a separate point-read probe fell from 3.2–3.3 ms to 1.7 ms, against 0.9 ms for point reads with nothing else running. Range and paged read throughput fell by 1–5%.
