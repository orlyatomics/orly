- **Changed**: the batch-backlog smoke's default `ROLLBACK_MAX` is now 512 rather than 16. On a fast machine the pool sits near full and a merge that recovers still rolls back 32 or 64 times in a row (master's own build does, 4 runs in 4), so 16 failed the job on runner speed alone. A merge that is stuck rolls back without end, which 512 still catches, and the smoke's drain and backlog checks catch it too.
