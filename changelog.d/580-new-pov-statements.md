- **Fixed**: the Python and TypeScript clients, and so the MCP server's `orly_new_pov` tool, built invalid statements for every POV except the default. `new_pov(safe=False)` / `newPov({ safe: false })` sent `new shared pov;`, but the grammar requires a guarantee, so it now sends `fast`. `parent=` sent `parent "<id>"`, but the grammar spells it `from {<id>}`. `docs/PROTOCOL.md` documented the same wrong forms and is corrected. A new CI smoke (`clients/smoke/run-new-pov.sh`) has both drivers create every flavour, with and without a parent, and write and read through each one (#580).
