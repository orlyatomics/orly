- **Fixed**: a file service destroyed before its runner fiber had ever run never gave that fiber's frame back, and the process later terminated with "Stack frame was not unwound properly" when its fiber frame pool was destroyed. This hit tests and short-lived tools that open and close an engine quickly, and could hit a server that failed right after startup. The destructor now frees the frame itself when the runner's host job never ran, and otherwise waits for the runner to finish, as the durable manager already does for its fibers (#631).
