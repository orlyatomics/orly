- **Changed (performance)**: converting a variant value for a query result or a write no longer rebuilds its storage record per value (#946). The fixed-shape `$which` record type, each arm's optional type and the field order are now computed once per variant type and cached on `Type::TVariant`. Encoding a variant value builds no map, takes no interner lock and sorts nothing, and `Type::NewSabot` reuses the same cached record. The bytes written and the types produced are unchanged.
