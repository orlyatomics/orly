- **Fixed (performance)**: The sort files that merges and memory-layer flushes spill to disk no longer go into the page cache. `TIndexManager` already chose a block-cache-only instruction for them, since they are only ever read back through the block cache, but the sort file never used it: every block it wrote was cached as sixteen pages too. Each of those pages needed a page buffer, so spilling evicted pages that readers were using and spent merge time in `TCache::NewPageBuf` finding buffers for pages no reader would ask for. `TOutStream` now takes a cache instruction as well as the old cache-or-clear flag, and the sort file passes it to its streams and its collision blocks.
