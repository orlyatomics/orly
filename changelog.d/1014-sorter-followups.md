- **Changed**: `TSorter` now states with `static_assert`s that its value type is nothrow-move-constructible, trivially destructible and no more aligned than `malloc` guarantees, which it relies on; `TUuid`'s move constructor and move assignment are marked `noexcept` so the types holding one pass. The fold checks whether each index's entries are already in order before `std::stable_sort`, which otherwise takes a scratch buffer of up to half the range; the written bytes are unchanged for keys that order totally (#1014).
