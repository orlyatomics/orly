- **Fixed (performance)**: A range read now spends about 13% fewer cycles per read quiet and 5% fewer under ingest building its result. The result's note interner is an open-addressing set, so interning a note no longer allocates a node for it. A disk arena now takes one cache reference per page it reads notes from and counts its own pins on that page, instead of retaining and releasing the cache block for every note. In a 64-session closed loop of 1,000-row integer ranges, in A C B B C A order, cycles per read fell from 3.87M to 3.37M quiet and from 5.59M to 5.30M under ingest. Range reads per second held at about 2,800 quiet and rose 2% under ingest. Page reads rose from 4,320 to 5,170 per second quiet ([#1018](https://github.com/orlyatomics/orly/issues/1018)).
