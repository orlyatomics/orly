- **Fixed**: `core_import` discarded the futures returned by `BeginImport()` and `EndImport()`, so import mode was not awaited before the import started and the end of import mode might not complete before exit; it now calls `Sync()` on each, as `orly_client` does, and a failure to end import mode after an error no longer masks the original error. The same warnings sweep fixed a mismatched `syslog` format in the disk volume manager, replaced pessimizing `return std::move(local)` with plain returns, made the two pool managers' "destroyed while owning pools" destructor failures an explicit `abort()` instead of a throw out of a destructor, marked the synth `TIfClause` `final` so its non-virtual destructor is safe, and re-enabled the compiler warnings that are now clean (everything the sweep covered, including `-Wimplicit-fallthrough`).
