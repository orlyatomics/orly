- **Added**: bounded history retention for reads at a version (#745 stage 2). `--retention_versions=N` and `--retention_seconds=S` (both off by default) keep the last N versions, or the last S seconds of them, through disk merges and `+=` folds, so `.at` reads inside the window no longer get `version_unavailable` once a merge has run. Inside the window a long `+=` run gets an Assign keyframe every 64 deltas, so a read replays at most 64 of them, and a range walk at a version stops replaying at the first Assign. A read at a version holds it for 10 minutes, renewed by each read. The on-disk format is unchanged: kept versions are ordinary history entries, which a 0.2.x binary reads. Master and slaves must be given the same flags; the server does not check this.
