- **Fixed**: a recursive sum-type value can now be part of a key. Reading such a key failed with "this sabot type double-visitor does not handle the recursive (TSelfRef) leaf", because key-prefix matching had no case for the recursive leaf. It now matches two leaves by de Bruijn depth, and when a leaf meets the spelled-out variant (a stored key's type is rebuilt from its value, while a `free::(T)` slot keeps the declared type) it unrolls the leaf to the variant it refers to, so key ranges with a free slot of recursive type see every stored key. No stored encoding changes. New lang test `variants_recursive_key.orly` (#980).
