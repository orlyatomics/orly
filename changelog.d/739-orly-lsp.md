- **Added**: an Orlyscript language server (`orly-lsp` / `orly_lsp`) speaking Language Server Protocol (LSP, JSON-RPC 2.0 over stdio) and a VS Code extension under `editors/vscode/`. Built on `orlyc`'s front end (syntax parsing, symbol generation, and type checking) so it stays in sync with the compiler: diagnostics as you type (syntax and semantic error reporting), hover documentation with deduced types, parameter descriptions, function signatures, and built-in keyword documentation (`keys`, `take`, `reduce`, `sorted_by`, `where`, etc.), go-to-definition for parameters and functions, document symbols for outline navigation, and code completions for keywords, primitive types, and names in scope. The VS Code extension provides full TextMate syntax highlighting (`syntaxes/orlyscript.tmLanguage.json`), snippets for packages, functions, and query patterns, LSP client integration, and a runner command to execute orlyscript against a local `orlyi` instance. LSP unit tests verify lifecycle, request handling, document caching, diagnostics, and request/response fixtures over the `lang_tests` corpus (#739).
