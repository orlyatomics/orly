- **Fixed**: a disk-backed slave (one run without `--mem_sim`) crashed when it joined. While syncing the master's data files it writes them to disk, and a disk write takes its event from the thread's own pool. The thread hosting the replication reader never had one, so the slave segfaulted in `TFileSync::Read` (#866). Runner-host threads now get a disk event pool when the server isn't simulating memory.
