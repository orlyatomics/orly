- **Changed**: a stream writing a disk file (a merge, a flush, an index) now has at most 64 blocks in flight. It used to hand every block to the disk as soon as it filled and wait only at the end, so a large merge held a disk event and a 64 KB buffer for each block it had written but the disk had not yet completed. With several merges at once that had no bound below the size of the disk event pool. A stream now waits for room before submitting each group of 16 blocks.
